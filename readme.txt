Einfaches Tool zum Umbenennen von Dateien in Form eines Text-Editors.
Es bietet Suchen/Ersetzen, einen Makro-Recorder sowie ein Ersetzungsmechanismus mit Hilfe
von regulären Ausdrücken

Version 1.0.1
Voraussetzungen Windows 8 oder höher

##################################

A simple tool for renaming files, in the form of a text editor.
It offers search and replace, a simple macro recorder and a replacement mechanism using
regular expressions

Version 1.0.1
System requirements: Windows 8 or later
